# 傾き迷路

スマートフォンの傾きセンサーで玉を転がし、穴に落とす 3D Web ゲームを作る。

ShibaLab 夏合宿 開発講座「スマホを傾けて遊ぶ 3D Web ゲームをつくろう」の教材。
HTML / CSS / JavaScript / Git の基礎を扱う。

完成したゲームは GitHub Pages で公開し、URL や QR コードでそのまま友達のスマホで遊べる。

---

## この講座だけの決めごと

GitHub アカウントの作り方、VSCode の使い方、git コマンドといった一般的な手順は
講師が配る記事を見てください。ここには**この講座でしか出てこないこと**だけ書いてあります。

### 1　教材のダウンロード

<https://github.com/uni-bit/shibalab-tilt-maze/archive/refs/heads/main.zip>

GitHub のアカウントが無くても落とせます（zip、約170KB）。

### 2　置き場所は `C:\Users\<自分の名前>\shibalab\tilt-maze`

**デスクトップに置かないでください。**
OneDrive を使っていると、デスクトップの本当の場所が
`C:\Users\<名前>\OneDrive\デスクトップ` にずれていることがあり、
2日目に git がフォルダを見つけられなくなります。

エクスプローラーのアドレス欄に `%USERPROFILE%` と入れると、置くべき場所が開きます。

### 3　展開すると、フォルダが二重になります

zip を右クリック → **すべて展開** → 展開先を `C:\Users\<自分の名前>\shibalab` と**手で入力**。
そのあとフォルダ名を `tilt-maze` に変えてください。

こうなっていれば正解です。

```
C:\Users\<自分の名前>\shibalab\tilt-maze\
├── index.html      ← 自分で書く
├── style.css       ← 自分で書く
├── game.js         ← 自分で書く
├── engine.js       ← 触らない
├── three.min.js    ← 触らない
├── sensor-check.html
└── docs\session3.md
```

**`index.html` が `tilt-maze` の直下にあること。**
中にまた `shibalab-tilt-maze-main` というフォルダがあったら、
その中身を全部 1つ上へ移動してください。

> zip を開いたまま中のファイルを編集しないこと。保存しても消えます。

### 4　自分のリポジトリは「Use this template」で作る

<https://github.com/uni-bit/shibalab-tilt-maze> → 緑の **Use this template**

> このボタンは**ログインしていないと表示されません。**

こうすると `engine.js` と `three.min.js` が最初から入った状態になるので、
以降アップロードするのは**自分が編集したファイルだけ**で済みます。

**Public のままにしてください。** Private だと公開できません。

### 5　1日目に書いたものは、2日目に手元へ戻ってきます

1日目は git を使わず、**編集したファイルを GitHub の画面から
アップロード**して公開します（Add file → Upload files）。

2日目は git を導入し、`git clone` で**自分のリポジトリを手元にコピー**します。
このとき、**新しいフォルダができます。**

```
C:\Users\<自分の名前>\shibalab\
├── tilt-maze-day1\   ← 1日目に使ったもの。もう使わないが消さない
└── tilt-maze\        ← clone したもの。★2日目からはこちらで作業する
```

**2日目以降は clone した方で作業してください。**
1日目のフォルダを編集しても、GitHub には反映されません。

> **1日目のフォルダは消さないこと。**
> もしアップロードし損ねていた場合、1日目の作業はそこにしか残っていません。
> clone した中身が1日目の状態になっていなければ、
> 1日目のフォルダから `index.html` と `style.css` をコピーしてください。

### 6　画面の確認にサーバーは要りません

`index.html` を**ダブルクリック**するだけでブラウザに表示されます。
編集して保存したら **F5**。変わらないときは **Ctrl + Shift + R**。

Live Server などの拡張機能も、Python も入れなくて大丈夫です。

> スマホで見るときだけは、GitHub Pages の公開 URL を使います。
> センサーは `https://` でないと動かないので、`file://` では試せません。

## はじめる前に

### 事前準備

- **VSCode** と **Git Bash** をインストールしておく
- **スマートフォン**（iPhone は Safari、Android は Chrome）
- **PC とスマホの両方**を持参、充電しておく

### GitHub アカウントについて

アカウントは**初日にその場で作ります**。事前に作る必要はありません。
ただし次の2つだけ、来る前に思い出しておいてください。

- **自分のメールにその場でログインできること。** アカウント作成時に
  認証コードがメールに届きます。パスワードを忘れていると進めません
- **GitHub のユーザー名の候補を 2〜3 個。** 先着順なので、
  短い名前はすでに使われていることが多いです

### 自分の端末が対応しているか確認する

初日に [`sensor-check.html`](sensor-check.html) を**スマホで**開いて確認します。
アカウント作成の待ち時間にやるので、先に済ませておく必要はありません。

- 緑（✅ 正常に動作しています）が出て、白い丸が傾きに追従すれば OK
- 赤（❌）が出た場合は、**担当者に伝えてください**

## engine.js が用意している関数

`game.js` からは次のものが使えます。覚えるのはこれだけです。

```js
BOARD_W                 // 盤の幅   300
BOARD_H                 // 盤の高さ 400

tilt.x                  // 左右の傾き  -1 〜 1（右に倒すと +）
tilt.y                  // 前後の傾き  -1 〜 1（手前に倒すと +）

drawBall(x, y)          // 玉を描く
drawWall(x, y, w, h)    // 壁を描く。x, y は左上の角
drawGoal(x, y, r)       // ゴールの穴を描く。x, y は中心、r は半径
```

`game.js` に `function update() { ... }` を書くと、engine が毎フレーム（1秒に約60回）呼び出します。

座標は左上が `(0, 0)`、右下が `(BOARD_W, BOARD_H)`。
**y は下向きが正**で、数学のグラフとは上下が逆です。

## 公開する

### 勉強会(1)（git を使わない方法）

1. GitHub で自分のリポジトリを開く
2. **Add file → Upload files**
3. ファイルをドラッグして **Commit changes**
4. **Settings → Pages** で Source を `Deploy from a branch`、Branch を `main` / `(root)` に
5. 数十秒待って、表示された URL をスマホで開く

### 勉強会(2)以降（git を使う方法）

```bash
git add .
git commit -m "変更した内容"
git push
```

公開 URL は `https://<GitHubユーザー名>.github.io/<リポジトリ名>/` の形になります。

## 動かないときは

エラーは**画面の下に赤い帯で表示されます**。まずそれを読んでください。

### 画面が真っ白／何も起きない

- `index.html` の `<script>` タグを3つとも書いたか
- 順番が `three.min.js` → `engine.js` → `game.js` になっているか
- ファイル名のつづりが合っているか（`style.css` を `styles.css` にしていないか）

### CSS が効かない

- CSS はエラーを出さずに黙って無視します。**まず `;` と `}` の書き忘れを疑う**
- セレクタの `#`（id）や `.`（class）を書き忘れていないか

### スマホでセンサーが反応しない

- **`https://` で開いているか。** `http://` や `file://` では動きません（GitHub Pages は自動で https になります）
- **iPhone で一度「許可しない」を選ぶと再表示されません。** Safari の設定からこのサイトのデータを削除するか、プライベートブラウズで開き直す
- **Android** の場合、Chrome のサイト設定でモーションセンサーがブロックされていないか
- 縦持ちで試す。開始ボタンを押した瞬間の姿勢が基準になります
- どうしても駄目なら矢印キーで開発を進められます

### 保存したのに変わらない

- 保存したか（Ctrl + S）
- キャッシュ。`Ctrl + Shift + R` で再読み込み
