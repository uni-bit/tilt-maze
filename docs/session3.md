# 勉強会(3)　ゲームにする

前回作った `game.js` に続きを書く。ファイルは作り直さない。

追加で使える関数

```
drawWall(x, y, w, h)   壁を描く。x, y は左上の角
drawGoal(x, y, r)      ゴールの穴を描く。x, y は中心、r は半径
```

STEP 1 と 2 で**ゲームとして完成**します。STEP 3 と 4 で壁を足して難しくします。

**時間が足りなければ STEP 3・4 は飛ばして構いません。** 壁が無くても
「傾けて穴に落とす」ゲームは成立しています。

## STEP 1　ゴールと、クリアの表示

### 1-1　ゴールを置く

```js
let goal = { x: 45, y: 330, r: 22 };
```

`update()` の中、`drawBall()` より前に描く。

```js
drawGoal(goal.x, goal.y, goal.r);
```

### 1-2　入ったかを判定する

玉とゴールの中心の距離が、半径より小さければ入っている。距離は三平方の定理で求める。

```js
let dx = ball.x - goal.x;
let dy = ball.y - goal.y;
let dist = Math.sqrt(dx * dx + dy * dy);
```

`dist` が `goal.r` より小さければクリア。クリアしたかどうかを覚えておく変数を、ファイルの上の方に用意する。

```js
let cleared = false;
```

### 1-3　画面に出す

まず `index.html` に、メッセージを出す場所を1つ足す。中身は空でよい。

```html
<p id="message"></p>
```

`style.css` で見た目を決める。大きさ、色は自由。

そして `game.js` から書き換える。

```js
document.getElementById("message").textContent = "CLEAR";
```

`document.getElementById("message")` は、HTML の中から `id="message"` の要素を探して取ってくるという意味。`textContent` がその要素の文字。これに代入すると表示が変わる。

**HTML で置いた場所を、CSS で飾って、JavaScript で書き換える。** 3つのファイルが1つの機能でつながる。

**確認**　玉をゴールに入れると CLEAR と表示される。

**ここでゲームとして成立しました。** 一度 push して、スマホで遊んでみてください。

## STEP 2　タイマー

`index.html` の `<p id="timer">` は、勉強会(1)で作ったまま `00.0` が固定表示されている。これを実際の経過時間にする。

やること

- ゲーム開始時刻を覚える。現在時刻は `Date.now()` でミリ秒で取れる
- 毎フレーム、開始からの経過秒を計算する
- `#timer` の `textContent` に入れる
- クリア後は止める

> **開始時刻を覚えておく変数は、`cleared` と同じように `update()` の外に書く。**
> `update()` の中に書くと毎フレーム上書きされてしまい、
> 経過時間がいつまでも `0.0` のままになります。

小数第1位までにするには `toFixed(1)` を使う。

```js
let sec = 12.3456;
sec.toFixed(1);   // "12.3"
```

STEP 1-3 と同じ書き方で要素を取得する。

**確認**　時間が進み、クリアで止まる。

## STEP 3　壁を置く

ここまでで遊べるようになりましたが、穴に向けて傾けるだけなので簡単すぎます。
**間に壁を置いて、難しくします。**

壁は何本も置くので、1本ずつ変数を作らずに**配列**にまとめる。`update()` の外に書く。

```js
let walls = [
  { x: -20, y: 120, w: 230, h: 16 },
  { x: 90,  y: 250, w: 230, h: 16 },
];
```

`x, y` は左上の角、`w, h` は幅と高さ。`[ ]` で囲んだものが配列で、`,` で区切って並べる。

x が `-20` になっているのは、**壁を盤の外まで少しはみ出させている**から。
ちょうど端（0 や 300）で終わらせると、盤のふちに張り付いた玉が
すり抜けてしまう。壁を足すときも、盤のふちに接する側は外まで伸ばしておく。

`update()` の中、`drawGoal()` と `drawBall()` の間に書く。**ここはコピーして貼ってよい。**

```js
for (let i = 0; i < walls.length; i++) {
  drawWall(walls[i].x, walls[i].y, walls[i].w, walls[i].h);
}
```

`walls.length` は入っている数。`i` を 0 から1ずつ増やしながら `walls[i]` で1本ずつ取り出している。

壁を増やしたいときは**配列に1行足すだけ**でよく、この `for` は変えなくて済む。これが配列を使う理由。

**確認**　盤に壁が2本現れる。玉はまだすり抜ける。

数字を変えて、好きな位置・長さにしてみる。盤は横 300、縦 400。

## STEP 4　壁に当たり判定をつける

ここが一番難しい。順を追って進める。

### 4-1　当たっているかを調べる関数（コピペでよい）

`update()` の外に書く。**ここは自分で考えなくてよい。コピーして貼る。**

```js
function hitWall() {
  for (let i = 0; i < walls.length; i++) {
    let w = walls[i];
    if (ball.x > w.x && ball.x < w.x + w.w &&
        ball.y > w.y && ball.y < w.y + w.h) {
      return true;
    }
  }
  return false;
}
```

玉の座標が、壁の左端と右端の間にあり、かつ上端と下端の間にもあるなら、その壁の中にいる。`&&` は「かつ」。

`return true` はその場で関数を抜けて「当たっている」と答える、という意味。
どの壁にも当たらなければ最後の `return false` に届く。

### 4-2　めり込んだら戻す

考え方は、**x と y を別々に動かして、別々に判定する**。

これまでは x と y を同時に動かしていた。それを分ける。

```js
let prevX = ball.x;
ball.x = ball.x + ball.vx;
if (hitWall()) {
  ball.x = prevX;
  ball.vx = -ball.vx * 0.5;
}
```

x を動かす前の値を覚えておき、動かした結果が壁の中なら元に戻して反転する。

次に、同じことを y でやる。**ここは自分で書く。**

**なぜ分けるのか**　まとめて判定して両方戻すと、壁に沿って滑れなくなる。分けて処理すると、横壁に当たったときは縦方向の移動だけが残るので、壁を擦りながら進める。まとめた版も試して、動きの違いを確かめてみるとよい。

**確認**　玉が壁を通り抜けず、壁に沿って滑る。

## STEP 5　自由制作

ここから先は自分で決める。1つ以上やる。

**手をつけやすい**

- 反発係数、摩擦、傾きの効きを調整して手触りを詰める
- クリア時のメッセージを凝る

### 壁の増やし方

**`walls` の配列に1行足すだけ。** 描画も当たり判定も自動で効く。

```js
let walls = [
  { x: -20, y: 120, w: 230, h: 16 },
  { x: 90,  y: 250, w: 230, h: 16 },
  { x: 40,  y: 190, w: 16,  h: 90 },   // ← 足した
];
```

`w` より `h` を大きくすると縦向きの壁になる。盤は横 300、縦 400。

**少し考える**

- ベストタイムを保存する（`localStorage.setItem` / `getItem`）
- 落ちるとスタートに戻される穴を作る
- 壁に当たった回数を数えて表示する
- 制限時間を設けて、超えたら失敗にする
- リトライボタンを作る（`addEventListener` で `click` を拾う）

**挑戦**

- ステージを2つ持ち、クリアしたら次に進む
- 玉を2つにして、両方ゴールさせるとクリア
- センサー値にローパスフィルタをかけて手ぶれを抑える
- 効果音を鳴らす（`new Audio()`）
